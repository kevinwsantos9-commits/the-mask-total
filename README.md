# The Masked Morte (Fabric 1.21.1)

Suba esta pasta para um repositorio no GitHub. Va em **Actions > build > Artifacts > TheMaskedMorte** e baixe o .jar.
Coloque o .jar na pasta mods junto com o Fabric API (0.102.0+1.21.1 ou mais novo).

Uso: crie a mascara (receita no jogo, ou `/give @s themaskedmorte:mask`), coloque na cabeca e use:
- `/morph` vira o mob vivo mais proximo (24 blocos)
- `/morph <mob>` vira o mob escolhido (ex: `/morph minecraft:creeper`)
- `/unmorph` volta ao normal (tirar a mascara tambem desfaz)
